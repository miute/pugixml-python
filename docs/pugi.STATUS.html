Parsing Status

Parsing status, returned as part of XMLParseResult object.

See also

XMLParseStatus

Attributes

pugi.STATUS_APPEND_INVALID_ROOT = 15

Unable to append nodes since root type is not NODE_ELEMENT or NODE_DOCUMENT (exclusive to XMLNode.append_buffer()).

pugi.STATUS_BAD_ATTRIBUTE = 12

Parsing error occurred while parsing element attribute.

pugi.STATUS_BAD_CDATA = 8

Parsing error occurred while parsing CDATA section.

pugi.STATUS_BAD_COMMENT = 7

Parsing error occurred while parsing comment.

pugi.STATUS_BAD_DOCTYPE = 9

Parsing error occurred while parsing document type declaration.

pugi.STATUS_BAD_END_ELEMENT = 13

Parsing error occurred while parsing end element tag.

pugi.STATUS_BAD_PCDATA = 10

Parsing error occurred while parsing PCDATA section.

pugi.STATUS_BAD_PI = 6

Parsing error occurred while parsing document declaration/processing instruction.

pugi.STATUS_BAD_START_ELEMENT = 11

Parsing error occurred while parsing start element tag.

pugi.STATUS_END_ELEMENT_MISMATCH = 14

There was a mismatch of start-end tags (closing tag had incorrect name, some tag was not closed or there was an excessive closing tag).

pugi.STATUS_FILE_NOT_FOUND = 1

File was not found during XMLDocument.load_file().

pugi.STATUS_INTERNAL_ERROR = 4

Internal error occurred.

pugi.STATUS_IO_ERROR = 2

Error reading from file/stream.

pugi.STATUS_NO_DOCUMENT_ELEMENT = 16

Parsing resulted in a document without element nodes.

pugi.STATUS_OK = 0

No error.

pugi.STATUS_OUT_OF_MEMORY = 3

Could not allocate memory.

pugi.STATUS_UNRECOGNIZED_TAG = 5

Parser could not determine tag type.
